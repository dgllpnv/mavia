## 5 · Armadilhas que já custaram tempo — não redescubra

- **`psql` não interpola `:'var'` dentro de `DO $$ ... $$`.** O corpo é string
  opaca. Use `\gset` e `\if`, que ainda falham em voz alta quando não há linha.
- **Migrations são forward-only.** Nunca edite uma aplicada; crie a seguinte.
  `CREATE OR REPLACE FUNCTION` exige `SET ROLE <dono>` antes.
- **`REVOKE` de quem não é mais dono não falha** — emite `WARNING` e deixa
  `EXECUTE` para `PUBLIC`. Sempre `SET ROLE` antes.
- **Privilégio de leitura é exigido para toda coluna que a instrução toca** —
  `SELECT`, `WHERE`, `JOIN`, `RETURNING`. O erro diz "permission denied for
  table" e aponta a tabela, nunca a coluna.
- **`FORCE ROW LEVEL SECURITY` alcança o dono da tabela.** Uma policy `FOR
  SELECT` deixa o `INSERT` sem política nenhuma.
- **Centavos como texto no `jsonb`.** `JSON.parse` de número vira `double`, e a
  auditoria é onde alguém confere uma cobrança.
- **O Redis lê a configuração uma vez, ao iniciar** — `docker compose up -d` não
  recria um container cuja definição não mudou.
- **A imagem é construída na VPS** (`docker build -f apps/api/Dockerfile`), e o
  repositório de lá é atualizado por `git reset --hard origin/main`. **O push
  para o GitHub é do dono** — o ambiente bloqueia.
